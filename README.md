
# ATM Interface using Java

## Project Description
This project is a console-based ATM Interface
developed using Java and Object-Oriented Programming.

## Features
- User Login with ID and PIN
- Maximum 3 login attempts
- Withdraw Money
- Deposit Money
- Transfer Money
- Transaction History
- Insufficient Balance Validation

## Technologies Used
- Java
- VS Code
- OOP Concepts
- ArrayList
- HashMap

## Classes
1. Main.java
2. ATM.java
3. Account.java
4. Transaction.java
5. Bank.java
