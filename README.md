
# Number Guessing Game

## Project Description
This is a console-based game developed using Java.
The computer generates a random number between 1 and 100.
The player tries to guess the number within 7 attempts.

## Features
- Random number generation
- Too High and Too Low hints
- Maximum 7 attempts
- Correct guess message
- You Lost message when attempts are over
- Play Again option
- Round counter
- Score summary for multiple rounds
- Input validation

## Technologies Used
- Java
- Scanner
- Random
- ArrayList
- Loops
- Conditional Statements

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile: javac NumberGuessingGame.java
5. Run: java NumberGuessingGame
